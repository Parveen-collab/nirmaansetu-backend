Here is the step-by-step guide to package your latest code and update your Docker image.

---

### Step 1: Package the Latest Code into a JAR

Before building the Docker image, compile and bundle all your latest code changes into the runnable JAR file:

```powershell
.\mvnw.cmd clean package -DskipTests
```

> **Note:** This verifies and generates `target/nirmaansetu.jar` which is copied into the Docker image.

---

### Step 2: Ensure [Dockerfile](file:///c:/Users/Hp/nirmaansetu-backend/Dockerfile) is in Place

A [`Dockerfile`](file:///c:/Users/Hp/nirmaansetu-backend/Dockerfile) has been created in your project root with the following configuration:

```dockerfile
FROM eclipse-temurin:21-jdk-alpine
WORKDIR /app
VOLUME /tmp
COPY target/nirmaansetu.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "/app/app.jar"]
```

---

### Step 3: Make Sure Docker Desktop is Running

Ensure **Docker Desktop** is running on your machine before running Docker CLI commands.

---

### Step 4: Build the Updated Docker Image

In your project root directory (`c:\Users\Hp\nirmaansetu-backend`), run:

```powershell
docker build -t nirmaansetu-backend .
```

*If you are using Docker Hub or a remote registry, tag it with your username and version:*
```powershell
docker build -t your-dockerhub-username/nirmaansetu-backend:latest .
```

---

### Step 5: Replace Any Running Container

If you already have a container running the old image:

1. **Stop the old container:**
   ```powershell
   docker stop nirmaansetu-backend
   ```

2. **Remove the old container:**
   ```powershell
   docker rm nirmaansetu-backend
   ```

3. **Start the new container with your environment variables:**
   ```powershell
   docker run -d `
     --name nirmaansetu-backend `
     -p 8080:8080 `
     -e DB_PASSWORD="your_mysql_password" `
     -e TWILIO_ACCOUNT_SID="$env:TWILIO_ACCOUNT_SID" `
     -e TWILIO_AUTH_TOKEN="$env:TWILIO_AUTH_TOKEN" `
     -e TWILIO_PHONE_NUMBER="$env:TWILIO_PHONE_NUMBER" `
     nirmaansetu-backend
   ```

---

### Step 6: Verify the Running Container

- **Check logs:**
  ```powershell
  docker logs -f nirmaansetu-backend
  ```
- **Test in browser / Swagger:**
  Open `http://localhost:8080/swagger-ui/index.html` to confirm all endpoints are running on the new build.

---

### Step 7 (Optional): Push to Remote Registry / Docker Hub

If deploying to a cloud server or sharing:

```powershell
docker login
docker push your-dockerhub-username/nirmaansetu-backend:latest
```
