## Before Push

Run the following command for a complete project verification:

.\mvnw clean verify

This runs the configured Maven verification lifecycle, including tests and
project-specific verification plugins.

### Optional

Run only when needed:

.\mvnw test
    → Run tests during development.

.\mvnw clean install
    → Perform a full clean build and install the artifact locally.

.\mvnw clean install -DskipTests
    → Build without running tests.

## Important URLs
1. - Swagger UI: `http://localhost:8080/swagger-ui/index.html`
2. - OpenAPI JSON: `http://localhost:8080/v3/api-docs`
3. - Postman: Import `swagger-docs.json` from the root directory.
